# Snapline for Linux X11 (Phase 6a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Snapline runs on Linux X11 desktops with the same features as on Windows (capture, draw, copy, save, upload,
auto-hide of text, Copy Text, tray, shortcuts, settings, launch at login), and ships as a .deb, an AppImage and a
Flatpak for x86_64 and aarch64.

**Architecture:** The shared Rust code already runs on Linux; what is missing is the platform layer. Linux code goes in
`platform/linux.rs` (re-exported by `platform/mod.rs`, which is today's `platform.rs`), a GTK-free tray in
`linux_tray.rs` behind a small `tray.rs` API that Windows also uses, Tesseract text recognition in `tesseract_ocr.rs`,
and an egui message box in `message.rs`. Packaging lives in `windows-linux/linux/`. Wayland is Phase 6b: on Wayland
Snapline says it needs an X11 session and stops.

**Tech Stack:** Rust 2024 (stable), winit 0.30 (X11), x11rb 0.13, ksni 0.3 (StatusNotifierItem), zbus 5,
zbus-secret-service-keyring-store 1.0, tesseract-rs 0.4 linked to the system libtesseract 5, eframe 0.37, cargo-deb
3.8, linuxdeploy, flatpak-builder (org.freedesktop.Platform 26.08), GitHub Actions, OrbStack (Ubuntu 24.04 VM on the
Mac).

**Spec:** [docs/windows-linux.md](../windows-linux.md) (design; Phase 6: "Linux X11, then Linux Wayland (portals,
Flatpak)") and the Decisions section below (Barayuda's answers of 1 November 2026, and the choices made while
planning).

## Decisions

Barayuda, 1 November 2026:

| Question | Answer |
|---|---|
| Scope | 6a is X11 only. Wayland (portals for capture and shortcuts) is its own plan, 6b. On Wayland, 6a says it needs an X11 session. |
| Text recognition | Tesseract linked into Snapline (`tesseract-rs`), not a separate program. |
| Packages | AppImage, .deb and Flatpak. |
| Manual testing | An OrbStack Ubuntu 24.04 VM on this Mac; CI on GitHub's Ubuntu runners is the gate. |

Decided while planning (each is a ruling Barayuda can overturn at review):

| Topic | Choice | Why |
|---|---|---|
| How Tesseract is linked | `tesseract-rs` feature `use-system-tesseract`: link the system libtesseract 5 through pkg-config | The default feature downloads and compiles Tesseract inside `build.rs`, which breaks Flatpak's offline build and pulls unpinned code at build time. The .deb depends on the distro's library, the AppImage bundles it, the Flatpak builds it from a pinned tarball. |
| Face detection | None on Linux in 6a; the badge says "auto-hide incomplete" and the reason | No maintained, permissive Rust face detector without OpenCV; text (the common case) still works. |
| Tray | `ksni` (StatusNotifierItem over D-Bus) on Linux; `tray-icon` stays on Windows | `tray-icon` on Linux needs GTK, reports no clicks and no position. `ksni` is pure Rust and reports left clicks, so "tray click takes a screenshot" works. |
| Message boxes | Our own egui window (`snapline --message <text>`), as Settings is | rfd's Linux message box needs `zenity`, which many desktops and the Flatpak sandbox lack. |
| Share | Opens a new email with the screenshot attached (`xdg-email --attach`), like Email on macOS | Linux has no share sheet. Inside Flatpak `xdg-email` goes through the Email portal. |
| Print | Opens the screenshot in the image viewer and says "Press Ctrl+P there" | Linux has no print verb and no print dialog without GTK. |
| Temporary copies | `~/.cache/Snapline/temp` | `/tmp/Snapline` would be shared by every user of the PC; the second user could not write there. |
| App ID | `dev.barayuda.Snapline` | Matches the macOS bundle ID `dev.barayuda.snapline`. |
| Versions | x11rb 0.13 and zbus 5, not the newest 0.14 and 6 | `global-hotkey`, `arboard`, `xcap`, `ksni` and the keyring store use 0.13 and 5; a second copy of each adds build time and size for nothing (same rule as `windows-collections` 0.3 in Phase 5c). |
| glibc floor | Build on Ubuntu 24.04 | Ubuntu 22.04's Tesseract is 4.1; tesseract-rs needs 5. The AppImage then runs on glibc 2.39 or newer (Ubuntu 24.04, Debian 13, Fedora 40 and later). |

## Review Focus

1. **Several monitors, different sizes, one left of the primary (negative x).** Each overlay must cover exactly its own
   monitor. Pinned by `overlay_goes_on_the_monitor_it_captured` (Task 4).
2. **No Secret Service running** (i3, a bare Xfce, a server without GNOME Keyring or KWallet). Snapline must say uploads
   are off and what to install, not crash or hang. Pinned by `a_missing_keyring_says_what_to_install` (Task 6).
3. **No tray host** (GNOME without the AppIndicator extension, i3). Snapline must say the icon is hidden, which
   shortcuts still work, and how to show the icon. Pinned by `no_tray_note_says_how_to_get_the_icon` (Task 2).
4. **Paths with spaces, `%`, `$` or quotes** in the home folder, the AppImage path or the save folder. Autostart,
   Reveal and xdg-open must still find the file. Pinned by `exec_line_quotes_what_desktop_files_need` and
   `file_uris_escape_spaces` (Task 5).
5. **A Wayland session, or no display at all** (started from a text console or over SSH). Snapline must say why it
   cannot run and stop, never show black captures through XWayland. Pinned by `wayland_and_console_sessions_are_refused`
   (Task 1).

`windows-linux/linux/dev-vm.sh` (then `chmod +x`):

```bash
#!/usr/bin/env bash
# The OrbStack Ubuntu machine for building and trying Snapline for Linux on a Mac.
#   linux/dev-vm.sh setup       create it (once), install the build packages and Rust
#   linux/dev-vm.sh desktop     add an Xfce desktop to open with Screen Sharing
#   linux/dev-vm.sh flatpak     add flatpak-builder and the Flathub remote
#   linux/dev-vm.sh run CMD...  run CMD in windows-linux/ inside the machine
set -euo pipefail
here=$(cd "$(dirname "$0")/.." && pwd) # windows-linux/, the same path inside the machine
vm=snapline-dev
in_vm() { orb -m "$vm" bash -lc "$1"; }
case "${1:-}" in
setup)
  orb list | grep -q "^$vm " || orb create ubuntu:noble "$vm"
  in_vm "sudo apt-get update && grep -v '^\$' '$here/linux/apt-packages.txt' | xargs sudo apt-get install -y --no-install-recommends"
  in_vm 'command -v cargo >/dev/null || curl --proto =https --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --profile minimal'
  ;;
desktop)
  in_vm 'sudo apt-get install -y xfce4 xfce4-terminal tigervnc-standalone-server gnome-keyring'
  echo "1. Set a VNC password:  orb -m $vm vncpasswd"
  echo "2. Start the desktop:   orb -m $vm vncserver :1 -localhost no -xstartup startxfce4"
  echo "3. In Finder: Go → Connect to Server → vnc://$vm.orb.local:5901"
  ;;
flatpak)
  in_vm 'sudo apt-get install -y flatpak flatpak-builder && flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo'
  ;;
run)
  shift
  in_vm "cd '$here' && CARGO_TARGET_DIR=\$HOME/snapline-target $(printf '%q ' "$@")"
  ;;
*)
  sed -n '2,6p' "$0"
  exit 2
  ;;
esac
```

The target folder lives in the VM's own home: the Mac and the VM share `windows-linux/`, and their builds must not mix.

```rust
/// Said on Wayland: 6a supports X11 sessions only.
pub const WAYLAND: &str = "Snapline for Linux needs an X11 session for now; Wayland support is coming. Log out, \
     choose an X11 or Xorg session at the login screen (for example \"Ubuntu on Xorg\"), and start Snapline again.";
/// Said when there is no desktop at all.
pub const NO_DISPLAY: &str =
    "Snapline needs a desktop session. Start it from your desktop, not from a text console.";

/// Why Snapline cannot run in this session, or `None` when it can.
pub fn session_problem() -> Option<&'static str> {
    session_problem_for(
        std::env::var_os("XDG_SESSION_TYPE").as_deref(),
        std::env::var_os("WAYLAND_DISPLAY").is_some(),
        std::env::var_os("DISPLAY").is_some(),
    )
}

/// `session_type` is `$XDG_SESSION_TYPE`; `wayland` and `x11` say whether `$WAYLAND_DISPLAY` and `$DISPLAY` are set.
pub fn session_problem_for(session_type: Option<&OsStr>, wayland: bool, x11: bool) -> Option<&'static str> {
    let kind = session_type.and_then(OsStr::to_str).unwrap_or("");
    if kind == "wayland" || (wayland && kind != "x11") {
        Some(WAYLAND)
    } else if x11 {
        None
    } else {
        Some(NO_DISPLAY)
    }
}
```

Add to `tray.rs`, above the tests:

```rust
use crate::app::UserEvent;
use crate::icon::TrayState;
use snapline_overlay::Rect;
use winit::event_loop::EventLoopProxy;

/// What a tray menu item does.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum MenuAction {
    Take,
    Why,
    Settings,
    Quit,
}

/// One line of the tray menu.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Entry {
    Item {
        label: String,
        /// Shown beside the label: the shortcuts that do the same.
        shortcut: Option<String>,
        action: MenuAction,
    },
    Separator,
}

/// "Take Screenshot" with the shortcuts that work; "Why doesn't … work?" when some failed but not all (when none
/// work, the app has already said why); then Settings and Quit.
#[must_use]
pub fn menu(working: &[String], failed: &[String]) -> Vec<Entry> {
    let item = |label: String, action| Entry::Item {
        label,
        shortcut: None,
        action,
    };
    let mut menu = vec![Entry::Item {
        label: "Take Screenshot".into(),
        shortcut: (!working.is_empty()).then(|| working.join(", ")),
        action: MenuAction::Take,
    }];
    if !failed.is_empty() && !working.is_empty() {
        let why = format!("Why doesn't {} work?", failed.join(" or "));
        menu.push(item(why, MenuAction::Why));

        item("Settings…".into(), MenuAction::Settings),
        Entry::Separator,
        item("Quit Snapline".into(), MenuAction::Quit),
    ]);

mod windows_backend {
    use super::{Entry, MenuAction};
    use crate::app::UserEvent;
    use crate::icon::{self, TrayState};
    use std::sync::Mutex;
    use tray_icon::menu::{Menu, MenuEvent, MenuItem, PredefinedMenuItem};
    use tray_icon::{Icon, MouseButton, MouseButtonState, TrayIcon, TrayIconBuilder, TrayIconEvent};
    use winit::event_loop::EventLoopProxy;

    const IDS: [(&str, MenuAction); 4] = [
        ("take", MenuAction::Take),
        ("why", MenuAction::Why),
        ("settings", MenuAction::Settings),
        ("quit", MenuAction::Quit),
    ];

    pub fn new(menu: &[Entry], menu_on_click: bool, proxy: EventLoopProxy<UserEvent>) -> Result<TrayIcon, String> {
        let p = Mutex::new(proxy.clone());
        MenuEvent::set_event_handler(Some(move |e: MenuEvent| {
            let action = IDS.iter().find(|(id, _)| *id == e.id.0).map(|(_, a)| *a);
            if let (Some(action), Ok(p)) = (action, p.lock()) {
                let _ = p.send_event(UserEvent::Menu(action));
            }
        }));
        let p = Mutex::new(proxy);
        TrayIconEvent::set_event_handler(Some(move |e: TrayIconEvent| {
            if let TrayIconEvent::Click {
                button: MouseButton::Left,
                button_state: MouseButtonState::Up,
                ..
            } = e
                && let Ok(p) = p.lock()
            {
                let _ = p.send_event(UserEvent::TrayClicked);
            }
        }));
        TrayIconBuilder::new()
            .with_icon(icon(TrayState::Normal)?)
            .with_tooltip("Snapline")
            .with_menu(Box::new(build(menu)?))
            .with_menu_on_left_click(menu_on_click)
            .build()
            .map_err(|e| e.to_string())
    }

    pub fn build(entries: &[Entry]) -> Result<Menu, String> {
        let menu = Menu::new();
        for entry in entries {
            match entry {
                Entry::Separator => menu.append(&PredefinedMenuItem::separator()),
                Entry::Item { label, shortcut, action } => {
                    let id = IDS.iter().find(|(_, a)| a == action).map_or("take", |(id, _)| *id);
                    let text = shortcut.as_ref().map_or_else(|| label.clone(), |s| format!("{label}\t{s}"));
                    menu.append(&MenuItem::with_id(id, text, true, None))
                }
            }
            .map_err(|e| e.to_string())?;
        }
        Ok(menu)
    }

    pub fn icon(state: TrayState) -> Result<Icon, String> {
        Icon::from_rgba(icon::tray_rgba(32, state), 32, 32).map_err(|e| e.to_string())
    }
}
```

```rust
enum Running {
    Menu(Handle<Item<true>>),
    Capture(Handle<Item<false>>),
}

pub struct LinuxTray {
    running: Running,
    proxy: EventLoopProxy<UserEvent>,
}

impl LinuxTray {
    pub fn new(menu: &[Entry], menu_on_click: bool, proxy: EventLoopProxy<UserEvent>) -> Result<Self, String> {
        let running = spawn(menu, pixmap(TrayState::Normal), menu_on_click, &proxy)?;
        Ok(Self { running, proxy })
    }

    pub fn set_menu(&mut self, menu: &[Entry], menu_on_click: bool) -> Result<(), String> {
        let menu = menu.to_vec();
        match (&self.running, menu_on_click) {
            (Running::Menu(h), true) => drop(h.update(|t| t.menu = menu)),
            (Running::Capture(h), false) => drop(h.update(|t| t.menu = menu)),
            (old, _) => {
                match old {
                    Running::Menu(h) => h.shutdown().wait(),
                    Running::Capture(h) => h.shutdown().wait(),
                }
                self.running = spawn(&menu, pixmap(TrayState::Normal), menu_on_click, &self.proxy)?;
            }
        }
        Ok(())
    }

    pub fn set_state(&self, state: TrayState) {
        let icon = pixmap(state);
        match &self.running {
            Running::Menu(h) => drop(h.update(|t| t.icon = icon)),
            Running::Capture(h) => drop(h.update(|t| t.icon = icon)),
        }
    }
}

/// Starts the item even when no panel is up yet (login): `watcher_offline` then tells the app.
fn spawn(menu: &[Entry], icon: ksni::Icon, menu_on_click: bool, proxy: &EventLoopProxy<UserEvent>) -> Result<Running, String> {
    let menu = menu.to_vec();
    let proxy = proxy.clone();
    let failed = |e: ksni::Error| format!("the desktop's tray service did not answer ({e})");
    if menu_on_click {
        Item::<true> { menu, icon, proxy }
            .assume_sni_available(true)
            .spawn()
            .map(Running::Menu)
            .map_err(failed)
    } else {
        Item::<false> { menu, icon, proxy }
            .assume_sni_available(true)
            .spawn()
            .map(Running::Capture)
            .map_err(failed)
    }
}
```

```rust
/// The user's runtime folder (`$XDG_RUNTIME_DIR`, private to the user), or the temp folder.
fn runtime_dir() -> PathBuf {
    dirs::runtime_dir().unwrap_or_else(std::env::temp_dir)
}

/// Lock files held for the life of the process.
static HELD: Mutex<Vec<File>> = Mutex::new(Vec::new());

/// `name` is the Windows mutex name (`Local\dev.barayuda.snapline`); its last part names the lock file.
pub fn claim(name: &str) -> bool {
    let file = name.rsplit('\\').next().unwrap_or(name);
    claim_at(&runtime_dir().join(format!("{file}.lock")))
}

/// False when another process holds the lock on `path`. When no lock can be made at all, Snapline runs.
pub fn claim_at(path: &Path) -> bool {
    let Ok(file) = File::options().create(true).truncate(false).write(true).open(path) else {
        return true;
    };
    match file.try_lock() {
        Ok(()) => {
            HELD.lock().unwrap_or_else(PoisonError::into_inner).push(file);
            true
        }
        Err(std::fs::TryLockError::WouldBlock) => false,
        Err(std::fs::TryLockError::Error(_)) => true,
    }
}

/// Calls `notify` for every datagram sent to `path`. Only the tray app listens, and it holds the claim, so a socket
/// file left behind by a crash is safe to replace.
pub fn watch_at(path: PathBuf, notify: impl Fn() + Send + 'static) {
    let _ = std::fs::remove_file(&path);
    let Ok(socket) = UnixDatagram::bind(&path) else {
        return;
    };
    std::thread::spawn(move || {
        let mut buf = [0u8; 16];
        while socket.recv(&mut buf).is_ok() {
            notify();
        }
    });
}

/// Nothing happens when the tray app is not running.
pub fn announce_at(path: &Path) {
    if let Ok(socket) = UnixDatagram::unbound() {
        let _ = socket.send_to(b"settings", path);
    }
}
```

```rust
/// A connection to the X server and its root window.
fn x11() -> Option<(RustConnection, u32)> {
    let (conn, screen) = x11rb::connect(None).ok()?;
    let root = conn.setup().roots.get(screen)?.root;
    Some((conn, root))
}

fn atom(conn: &RustConnection, name: &str) -> Option<u32> {
    Some(conn.intern_atom(false, name.as_bytes()).ok()?.reply().ok()?.atom)
}

pub fn beep() {
    if let Some((conn, _)) = x11() {
        let _ = conn.bell(0);
        let _ = conn.flush();
    }
}

pub fn cursor_position() -> Option<(i32, i32)> {
    let (conn, root) = x11()?;
    let pointer = conn.query_pointer(root).ok()?.reply().ok()?;
    Some((pointer.root_x.into(), pointer.root_y.into()))
}

/// The part of `monitor` inside `work`, or `None` when they do not overlap.
#[must_use]
pub fn clip(monitor: Rect, work: Rect) -> Option<Rect> {
    let x = monitor.x.max(work.x);
    let y = monitor.y.max(work.y);
    let right = (monitor.x + monitor.width).min(work.x + work.width);
    let bottom = (monitor.y + monitor.height).min(work.y + work.height);
    (right > x && bottom > y).then(|| Rect::new(x, y, right - x, bottom - y))
}

/// `_NET_WORKAREA` of the current desktop: the screen without panels, as the window manager reports it.
fn net_workarea(conn: &RustConnection, root: u32) -> Option<Rect> {
    let current = conn
        .get_property(false, root, atom(conn, "_NET_CURRENT_DESKTOP")?, AtomEnum::CARDINAL, 0, 1)
        .ok()?
        .reply()
        .ok()?
        .value32()?
        .next()
        .unwrap_or(0);
    let areas: Vec<u32> = conn
        .get_property(false, root, atom(conn, "_NET_WORKAREA")?, AtomEnum::CARDINAL, 0, 1024)
        .ok()?
        .reply()
        .ok()?
        .value32()?
        .collect();
    let mut boxes = areas.chunks_exact(4);
    let a = boxes.clone().nth(current as usize).or_else(|| boxes.next())?;
    Some(Rect::new(f64::from(a[0]), f64::from(a[1]), f64::from(a[2]), f64::from(a[3])))
}

/// The usable part of the monitor under `(x, y)`, in physical pixels; `None` without a window manager.
pub fn work_area(x: i32, y: i32) -> Option<Rect> {
    let monitor = xcap::Monitor::all().ok()?.into_iter().find_map(|m| {
        let (mx, my) = (m.x().ok()?, m.y().ok()?);
        let (mw, mh) = (m.width().ok()?, m.height().ok()?);
        let inside = x >= mx && y >= my && i64::from(x) < i64::from(mx) + i64::from(mw) && i64::from(y) < i64::from(my) + i64::from(mh);
        inside.then(|| Rect::new(f64::from(mx), f64::from(my), f64::from(mw), f64::from(mh)))
    })?;
    let (conn, root) = x11()?;
    // ponytail: _NET_WORKAREA is one box for all monitors, so a panel on another monitor only can be missed.
    clip(monitor, net_workarea(&conn, root)?)
}

/// The X11 window id of `window`.
fn xid(window: &winit::window::Window) -> Option<u32> {
    use winit::raw_window_handle::{HasWindowHandle, RawWindowHandle};
    match window.window_handle().ok()?.as_raw() {
        RawWindowHandle::Xlib(h) => u32::try_from(h.window).ok(),
        RawWindowHandle::Xcb(h) => Some(h.window.get()),
        _ => None,
    }
}

/// Keeps `window` out of the taskbar and the pager. Must run before the window is first shown: the window
/// manager reads `_NET_WM_STATE` when the window maps.
pub fn hide_from_taskbar(window: &winit::window::Window) {
    let (Some((conn, _)), Some(id)) = (x11(), xid(window)) else {
        return;
    };
    let names = ["_NET_WM_STATE", "_NET_WM_STATE_SKIP_TASKBAR", "_NET_WM_STATE_SKIP_PAGER"];
    let [Some(state), Some(taskbar), Some(pager)] = names.map(|n| atom(&conn, n)) else {
        return;
    };
    let _ = conn.change_property32(PropMode::APPEND, id, state, AtomEnum::ATOM, &[taskbar, pager]);
    let _ = conn.flush();
}

/// Gives `window` the keyboard (Escape and the shortcuts must reach the overlay at once).
pub fn take_focus(window: &winit::window::Window) {
    if let (Some((conn, _)), Some(id)) = (x11(), xid(window)) {
        let _ = conn.set_input_focus(InputFocus::PARENT, id, x11rb::CURRENT_TIME);
        let _ = conn.flush();
    }
}

pub fn hide_from_alt_tab(window: &winit::window::Window) {
    hide_from_taskbar(window);
}

/// Popups are notification windows on X11 (`popup_window.rs`), which window managers never focus.
pub fn never_activate(_window: &winit::window::Window) {}
```

```rust
/// `file` as a `file://` URI.
pub fn file_uri(file: &Path) -> Result<String, String> {
    url::Url::from_file_path(file)
        .map(String::from)

/// Shows `file` selected in the file manager (`org.freedesktop.FileManager1`: Nautilus, Dolphin, Nemo, Caja,
/// Thunar); opens its folder when the file manager does not offer that.
pub fn reveal(file: &Path) {
    let selected = file_uri(file).and_then(|uri| {
        let bus = zbus::blocking::Connection::session().map_err(|e| e.to_string())?;
        bus.call_method(
            Some("org.freedesktop.FileManager1"),
            "/org/freedesktop/FileManager1",
            Some("org.freedesktop.FileManager1"),
            "ShowItems",
            &(vec![uri.as_str()], ""),
        )
        .map(drop)
        .map_err(|e| e.to_string())
    });
    if selected.is_err()
        && let Some(dir) = file.parent()
    {
        let _ = xdg_open(dir);
    }
}

/// How Snapline was installed, which decides the command that starts it at login.
#[derive(Debug, PartialEq, Eq)]
pub enum Install {
    Flatpak(String),
    AppImage(PathBuf),
    /// The .deb, or a build run in place.
    Plain(PathBuf),
}

#[must_use]
pub fn install() -> Install {
    if let Some(id) = std::env::var_os("FLATPAK_ID") {
        return Install::Flatpak(id.to_string_lossy().into_owned());
    }
    if let Some(path) = std::env::var_os("APPIMAGE") {
        return Install::AppImage(path.into());
    }
    Install::Plain(std::env::current_exe().unwrap_or_else(|_| "snapline".into()))
}

/// The `Exec=` value. Inside quotes the desktop entry spec wants `"`, `` ` ``, `$` and `\` escaped, and `%` doubled.
#[must_use]
pub fn exec_line(install: &Install) -> String {
    match install {
        Install::Flatpak(id) => format!("flatpak run {id}"),
        Install::AppImage(path) | Install::Plain(path) => {
            let mut out = String::from("\"");
            for c in path.to_string_lossy().chars() {
                match c {
                    '"' | '`' | '$' | '\\' => {
                        out.push('\\');
                        out.push(c);
                    }
                    '%' => out.push_str("%%"),
                    _ => out.push(c),
                }
            }
            out.push('"');
            out
        }
    }
}

/// `~/.config/autostart`. Inside Flatpak `$XDG_CONFIG_HOME` is the sandbox's own folder, so use the real one.
#[must_use]

/// Writes (`Some(exec)`) or removes (`None`) Snapline's autostart entry in `dir`.
pub fn set_autostart(dir: &Path, exec: Option<&str>) -> Result<(), String> {
    let file = dir.join(AUTOSTART_FILE);
    let done = match exec {
        Some(exec) => std::fs::create_dir_all(dir).and_then(|()| {
            std::fs::write(
                &file,
                format!(
                    "[Desktop Entry]\nType=Application\nName=Snapline\nExec={exec}\nIcon=dev.barayuda.Snapline\n\
                     Terminal=false\nX-GNOME-Autostart-enabled=true\n"
                ),
            )
        }),
        None => match std::fs::remove_file(&file) {
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(()),
            other => other,
        },
    };
    done.map_err(|e| format!("Snapline could not change {}: {e}", file.display()))
}
```

```rust
/// Where the English data may be, most specific first: `$TESSDATA_PREFIX`, inside the AppImage, inside the Flatpak,

pub fn tessdata_candidates(var: impl Fn(&str) -> Option<PathBuf>) -> Vec<PathBuf> {

/// Tesseract's TSV output as lines of words. Rows of level 5 are words; a word belongs to the line
/// (block, paragraph, line). Words with no text or no confidence (-1) are skipped.
#[must_use]
pub fn lines_from_tsv(tsv: &str) -> Vec<Line> {
    let mut lines: Vec<((u32, u32, u32), Line)> = Vec::new();
    for row in tsv.lines() {
        let cols: Vec<&str> = row.splitn(12, '\t').collect();
        let [level, _page, block, par, line, _word, left, top, width, height, conf, text] = cols[..] else {
            continue;
        };
        let text = text.trim();
        if level != "5" || text.is_empty() || !conf.parse::<f64>().is_ok_and(|c| c >= 0.0) {
            continue;
        }
        let n = |s: &str| s.parse::<u32>().ok();
        let (Some(block), Some(par), Some(line), Some(left), Some(top), Some(width), Some(height)) =
            (n(block), n(par), n(line), n(left), n(top), n(width), n(height))
        else {
            continue;
        };
        let word = Word {
            text: text.to_owned(),
            rect: Rect::new(f64::from(left), f64::from(top), f64::from(width), f64::from(height)),
        };
        match lines.last_mut() {
            Some((key, l)) if *key == (block, par, line) => l.words.push(word),
            _ => lines.push(((block, par, line), Line { words: vec![word] })),
        }
    }
    lines.into_iter().map(|(_, l)| l).collect()
}

fn read(image: &Pixmap) -> Result<Vec<Line>, String> {
    let dir = tessdata().ok_or_else(no_tessdata)?;
    let failed = |e: tesseract_rs::TesseractError| format!("Tesseract could not read the screenshot: {e}");
    let api = TesseractAPI::new();
    api.init(&dir, "eng").map_err(failed)?;
    // Screens are 96 dpi or more; without this Tesseract guesses 70 and reads small text worse.
    api.set_variable("user_defined_dpi", "96").map_err(failed)?;
    let (w, h) = (image.width().cast_signed(), image.height().cast_signed());
    // The screenshot is opaque, so tiny-skia's premultiplied RGBA is plain RGBA.
    api.set_image(image.data(), w, h, 4, w * 4).map_err(failed)?;
    api.recognize().map_err(failed)?;
    Ok(lines_from_tsv(&api.get_tsv_text(0).map_err(failed)?))
}

impl Recognizer for Tesseract {
    fn recognize(&self, image: &Pixmap, text: bool, faces: bool) -> Result<Reading, String> {
        merge(text.then(|| read(image)), faces.then(|| Err(NO_FACES.to_owned())))
    }
}
```

```bash
#!/usr/bin/env bash
# Builds the .deb and the AppImage for this machine's architecture into target/dist, with checksums.
# Usage: linux/package.sh <version>      (run in windows-linux/, after `cargo build --release -p snapline`)
set -euo pipefail
cd "$(dirname "$0")/.."
version=$1
target=${CARGO_TARGET_DIR:-target}
arch=$(uname -m) # x86_64 or aarch64
deb_arch=$([ "$arch" = x86_64 ] && echo amd64 || echo arm64)
out=$target/dist
mkdir -p "$out"

cargo deb -p snapline --no-build --deb-version "$version" -o "$out/snapline_${version}_${deb_arch}.deb"

# AppImage: linuxdeploy copies snapline and the libraries it links (Tesseract, Leptonica) into an AppDir; the English
# data goes where Snapline looks for it ($APPDIR/usr/share/tesseract-ocr/5/tessdata).
appdir=$target/AppDir
rm -rf "$appdir"
install -Dm644 /usr/share/tesseract-ocr/5/tessdata/eng.traineddata "$appdir/usr/share/tesseract-ocr/5/tessdata/eng.traineddata"
tool=$target/linuxdeploy-$arch.AppImage
if [ ! -x "$tool" ]; then
  curl -fsSL -o "$tool" "https://github.com/linuxdeploy/linuxdeploy/releases/download/continuous/linuxdeploy-$arch.AppImage"
  chmod +x "$tool"
fi
sha256sum "$tool" # the tool comes from a moving "continuous" release: keep its checksum in the log
APPIMAGE_EXTRACT_AND_RUN=1 LDAI_OUTPUT="$out/Snapline-$version-$arch.AppImage" "$tool" --appdir "$appdir" \
  --executable "$target/release/snapline" --desktop-file linux/dev.barayuda.Snapline.desktop \
  --icon-file linux/dev.barayuda.Snapline.png --output appimage

(cd "$out" && sha256sum -- *.deb *.AppImage >"SHA256SUMS-linux-$arch.txt")
```

```markdown
# Releasing Snapline for Linux

1. Pull `main` (with the Linux work merged) and check that CI is green on both Linux runners.
2. Set the version in `windows-linux/crates/snapline/Cargo.toml` and add a `<release version="…" date="…"/>` line at
   the top of `<releases>` in `windows-linux/linux/dev.barayuda.Snapline.metainfo.xml`. Commit.
3. Tag that commit `linux-v<version>` (for example `linux-v0.1.0`) and push the tag. The **linux-release** workflow
   checks the version, runs the tests, builds the .deb, the AppImage and the Flatpak for x86_64 and aarch64, and
   creates a **draft** release with `SHA256SUMS.txt`.
4. Download one package per kind, try it in the VM (`windows-linux/linux/dev-vm.sh desktop`), then publish the draft.

To redo a release: delete the draft and the tag (`git push --delete origin linux-v<version>`), fix, and tag again.

The Windows release (`windows-v…` tags) is separate: see [releasing-windows.md](releasing-windows.md).
```
